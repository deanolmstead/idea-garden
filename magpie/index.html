magpie

Paste a video link. magpie fetches it through your local yt-dlp helper.

GitHub Pages mode: start the Mac helper first: cd ~/idea-garden/magpie && source .venv/bin/activate && python3 -m uvicorn app:app --reload. This page will call http://localhost:8000 for yt-dlp downloads.

Tip: works with most video pages. The server probes the link, then you pick a quality. Needs ffmpeg installed for merged HD & mp3.
