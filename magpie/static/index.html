magpie

Paste a video link. magpie fetches it through your local yt-dlp helper.

GitHub Pages mode: start the helper on this PC first. In PowerShell, from the magpie folder: .venv\Scripts\activate then python app.py (serves on port 8010). First time only: python -m venv .venv, .venv\Scripts\activate, pip install -r requirements.txt. This page tries ports 8000 and 8010. Current helper: detecting. Open local helper

Tip: works with most video pages. The server probes the link, then you pick a quality. Needs ffmpeg installed for merged HD & mp3.
